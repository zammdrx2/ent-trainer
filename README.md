# Тренажёр ЕНТ по информатике

Веб-приложение на Django для подготовки школьников к ЕНТ (ҰБТ) по информатике. Ученик регистрируется, решает тесты по темам или смешанный тест, сразу видит разбор ошибок с объяснениями и следит за успеваемостью по каждой теме. Преподаватель добавляет вопросы и смотрит результаты учеников через панель администратора.

Интерфейс и вопросы на **русском и казахском** языках.

## Возможности

- Регистрация и вход учеников
- Тесты по 8 темам и смешанный тест (20 случайных вопросов по всем темам)
- Вопросы с фрагментами кода на Python, варианты ответов перемешиваются
- Разбор после теста: правильный ответ и объяснение к каждому вопросу
- Личная статистика: процент правильных ответов по темам, список тем «стоит повторить», история тестов
- Переключение языка RU / ҚАЗ; если перевода нет, показывается русский текст
- Панель преподавателя (Django Admin): редактирование тем, вопросов и вариантов, результаты всех учеников
- Загрузка банка вопросов из JSON одной командой (без дублей при повторном запуске)
- Стартовый набор: 48 вопросов на двух языках

## Стек

Python 3.12 · Django 5 · PostgreSQL / SQLite · Docker · Gunicorn · WhiteNoise · GitHub Actions

## Архитектура

| Модуль | Назначение |
|---|---|
| `quiz/models.py` | Модели: `Topic`, `Question`, `Choice`, `TestAttempt`, `Answer`; двуязычные поля |
| `quiz/services.py` | Бизнес-логика: создание теста, проверка ответов, статистика по темам |
| `quiz/views.py` | Страницы: главная, тест, результат, статистика, регистрация |
| `quiz/ui.py` | Тексты интерфейса на двух языках |
| `quiz/admin.py` | Панель преподавателя |
| `quiz/management/commands/load_questions.py` | Импорт вопросов из JSON |
| `quiz/data/questions.json` | Стартовый банк вопросов |
| `quiz/tests.py` | Автотесты |

Проверка ответов вынесена из представлений в сервисный слой и защищена от подмены: вариант засчитывается, только если он принадлежит этому вопросу, а завершённый тест нельзя пересдать повторной отправкой формы.

## Запуск локально

```bash
git clone https://github.com/zammdrx2/ent-trainer.git
cd ent-trainer
python3 -m venv venv
source venv/bin/activate            # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env

python manage.py migrate
python manage.py load_questions     # загрузить 48 стартовых вопросов
python manage.py createsuperuser    # аккаунт преподавателя
python manage.py runserver
```

Откройте http://127.0.0.1:8000, панель преподавателя — http://127.0.0.1:8000/admin.

По умолчанию используется SQLite. Чтобы работать с PostgreSQL, раскомментируйте переменные `POSTGRES_*` в `.env`.

## Запуск в Docker (с PostgreSQL)

```bash
docker compose up --build
docker compose exec web python manage.py createsuperuser
```

## Тесты

```bash
python manage.py test
```

Тесты проверяют подсчёт баллов, защиту от подмены ответов, статистику, регистрацию, доступ к чужим попыткам и импорт вопросов. При каждом push тесты запускаются в GitHub Actions на PostgreSQL.

## Формат вопросов (JSON)

```json
{
  "name_ru": "Python: основы",
  "name_kk": "Python: негіздері",
  "questions": [
    {
      "ru": "Что выведет программа?",
      "kk": "Бағдарлама не шығарады?",
      "code": "print(7 // 2)",
      "choices": [["3", "3"], ["3.5", "3.5"], ["4", "4"]],
      "answer": 0,
      "d": 1,
      "exp_ru": "// — целочисленное деление.",
      "exp_kk": "// — бүтін бөлу."
    }
  ]
}
```

`answer` — индекс правильного варианта, `d` — сложность от 1 до 3. Свой файл загружается командой `python manage.py load_questions путь/к/файлу.json`.
